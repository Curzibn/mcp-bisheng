# 美团企业版开放平台

## 免登FAQ

## 1.员工信息查询失败/出错啦

登录时，如果出现【员工信息查询失败，请确认员工信息是否已录入美团企业版！】或者【出错啦】的报错情况，需要先到[美团企业版企业管理后台](https://sqt.meituan.com/index.html#/user/login)的【员工管理-组织架构】菜单中查询员工是否已经存在，如果查询不到报错员工，需要先确认员工不存在的原因后，再尝试登录。报错图片如下所示：  

### 问题排查指引

1.  确认员工唯一标识是工号、邮箱还是手机号；
2.  如果员工不存在，则先定位员工未同步成功的问题；
3.  如果员工已存在，则排查请求报文，确认[H5免登](https://bep-openapi.meituan.com/api/sqt/openplatform_web/site/index.html#/apiDoc/loginFree)接口中，staffInfo中的staffPhone或staffNum传值是否正确；
4.  上述排查步骤全部未发现问题，则联系客户经理进行内部排查，定位问题所需内容：entId、登录报错员工、登录请求报文和报错录屏。

## 2.您没有该业务的访问权限

登录时，如果出现【您没有该业务的访问权限，请联系客服处理】的报错情况，需要客户经理到运营后台确认场景和品类是否正确开通，然后到[美团企业版企业管理后台](https://sqt.meituan.com/index.html#/user/login)的【员工管理-员工权限】菜单中查询是否为登录员工开通了场景权限，报错图片如下所示：  

### 问题排查指引

1.  客户经理到【运营后台】查询场景和品类开通是否正确，并到【企业管理后台-员工管理-员工权限】查看员工权限是否开通正确；
2.  确认报错员工与免登报文中的唯一标识是否一致；
3.  如果场景和权限开通正确，则排查请求报文，确认[H5免登](https://bep-openapi.meituan.com/api/sqt/openplatform_web/site/index.html#/apiDoc/loginFree)接口中productType字段传值是否正确，例如企业开通的是工作餐-外卖，则productType可以传值为mt\_waimai（外卖商家列表页）、sqt\_home（美团企业版首页），但如果传mt\_train（火车票购买）则会报没有业务访问权限；
4.  上述排查步骤全部未发现问题，则进行内部排查，定位问题所需内容：entId、报错员工、登录请求报文和报错录屏。

## 3.添加用户失败

登录时，如果出现【添加用户失败】报错，首先确认是否需要在免登环节添加员工，另外需要确认员工唯一标识字段（staffPhone/staffNum）是否传值，例如，员工唯一标识是工号，但是在免登接口staffInfo中staffNum没有传值，而是只传了staffPhone，报错图片如下所示：  

## 4.美团企业版登录态异常,请稍后再试!

登录时如果报错"美团企业版登录态异常,请稍后再试!" 请确认获取到的302重定向链接是否多次使用，该链接不可多次使用，必须每次重新生成（详见H5免登接口文档）
