# 美团企业版开放平台

## 角色组保存接口

## 1.概述

角色组保存接口为角色管理体系中的第一步，如果企业需要用角色管理，需要按照：创建角色组→在角色组下创建角色→在角色中关联员工，这个顺序进行配置。

## 2.接口基本信息

| 名称 | 描述 |
| --- | --- |
| 请求方式 | POST |
| 调用地址 | 测试环境：`https://waimai-openapi.apigw.test.meituan.com/api/sqt/open/tag/group/batch/save`  
正式环境：`https://bep-openapi.meituan.com/api/sqt/open/tag/group/batch/save` |
| 调用方 | 客户平台 |
| 响应方 | 美团企业版 |
| 响应超时时间 | 5秒 |
| 调用限频 | 每分钟访问不超过100次，每天累计访问不超过100000次 |

#### content加密前数据结构

| 名称 | 类型 | 是否必填 | 示例 | 说明 |

| ts | Long | 是 | 1617085650321 | 13位时间戳。若请求发起时间与平台接受请求时间相差大于10分钟，平台将直接拒绝本次请求 |
| entId | Long | 是 | 46574 | 企业ID |
| tagGroupList | List<[TagGroup](https://bep-openapi.meituan.com/api/sqt/openplatform_web/site/index.html#/apiDoc/tagGroupSave#TagGroup)\> | 是 | 见[TagGroup](https://bep-openapi.meituan.com/api/sqt/openplatform_web/site/index.html#/apiDoc/tagGroupSave#TagGroup)字段说明 | 同步到美团企业版的角色组信息，单次最多同步50个角色组 |

**TagGroup字段说明**

| 名称 | 类型 | 是否必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| tagGroupType | Integer | 是 | 1 | 角色组类型，0：职级角色组（不可新增，该角色组唯一且已自动创建，只可更新），1：普通自定义角色组（可新增，可更新）当type传0时，仅可对职级角色组进行更新（tagGroupId传值自动忽略，externalTagGroupId传值仅可用于对该值进行更新）当type传1时，可新增或更新普通自定义角色组。新增角色组时，tagGroupId传空；更新角色组时，tagGroupId和externalTagGroupId二者必传其一，如果两个字段都传值，则以tagGroupId为准，进行数据更新； |
| tagGroupId | Long | 否 | 1 | 角色组ID，美团侧对角色组的唯一标识 |
| externalTagGroupId | String | 否 | A01 | 角色组编码，企业侧对角色组的唯一标识，如有传值，美团侧会进行存储 |
| tagGroupName | String | 否 | 职级 | 角色组名称，新增角色组时，此字段必传 |
| isDuplicate | Boolean | 否 | true | 角色组下允许一个员工有多个角色（false：同一角色组下，同一员工不允许属于多个角色；true：同一角色组下，同一员工允许属于多个角色），新增角色组不传该值时，默认为false |

| 10090113 | 角色组数量已达到系统限制，无法新增角色组 | 一个企业仅可创建200个角色组，不可超过此数量 |
| 10090114 | 不允许从【允许一个员工在多个角色】转换为【禁止一个员工在多个角色】 | 请检查isDuplicate传值，当角色组在新增时为【允许一个员工在多个角色】时，不允许调整为【禁止一个员工在多个角色】 |
