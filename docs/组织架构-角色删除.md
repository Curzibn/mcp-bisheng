# 美团企业版开放平台

## 角色删除接口

## 1.概述

角色删除接口为角色管理体系中删除的第二步，调用角色删除接口可以根据角色ID或角色编码删除在美团创建的角色，但在删除前需要保证角色中没有员工，删除顺序为：删除角色下员工→删除角色→删除角色组。

## 2.接口基本信息

| 名称 | 描述 |
| --- | --- |
| 请求方式 | POST |
| 调用地址 | 测试环境：`https://waimai-openapi.apigw.test.meituan.com/api/sqt/open/tag/batch/delete`  
正式环境：`https://bep-openapi.meituan.com/api/sqt/open/tag/batch/delete` |
| 调用方 | 客户平台 |
| 响应方 | 美团企业版 |
| 响应超时时间 | 5秒 |
| 调用限频 | 每分钟访问不超过100次，每天累计访问不超过100000次 |
