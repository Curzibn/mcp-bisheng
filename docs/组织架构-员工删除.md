# 美团企业版开放平台

## 员工删除接口

## 1.概述

员工批量删除接口，支持通过美团企业版员工唯一标识（staffId）、企业唯一标识（手机号、工号、邮箱）删除，单次最大删除员工数量为50

注：员工A删除后，再次同步到美团，会按照新增逻辑处理，历史申请单和订单会消失。

## 2.接口基本信息

| 名称 | 描述 |
| --- | --- |
| 请求方式 | POST |
| 调用地址 | 测试环境：`https://waimai-openapi.apigw.test.meituan.com/api/sqt/open/staff/batch/delete`  
正式环境：`https://bep-openapi.meituan.com/api/sqt/open/staff/batch/delete` |
| 调用方 | 客户平台 |
| 响应方 | 美团企业版 |
| 响应超时时间 | 15秒 |
| 调用限频 | 每分钟访问不超过100次，每天累计访问不超过100000次 |
