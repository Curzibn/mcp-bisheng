针对SPA（单页应用）类型的文档网站（如美团开放平台），静态爬虫无法获取内容，必须使用无头浏览器（如Puppeteer或Playwright）。

以下是区分和提取左右侧目录的**分析逻辑与TS实现策略**：

### 1. 核心区分逻辑 (Heuristic Logic)

依靠**DOM布局坐标**和**链接特征**是最通用的区分方式，不依赖特定class名。

| 特征 | 左侧大目录 (Global Nav) | 右侧小目录 (On-page TOC) |
| --- | --- | --- |
| **屏幕位置** | `x` 坐标接近 0，宽度通常在 200-300px | `x` 坐标接近屏幕右侧，通常 `fixed` 定位 |
| **链接行为** | 点击后 URL **路径(Path)** 改变，或 Hash `#` 大段变化 | 点击后 URL 仅 Hash 后缀变化，或滚动到当前页锚点 |
| **内容对应** | 包含“概览”、“接口列表”等跨页面标题 | 高度匹配当前正文中的 `<h2>`, `<h3>` 文本 |
| **DOM结构** | 往往嵌套深（多级菜单），含有 `折叠/展开` 交互 | 结构扁平，通常仅 1-2 层级 |

### 2. 分析与提取流程 (TypeScript + Puppeteer)

#### 第一步：定位容器 (Container Detection)

不要直接找 `ul/li`，先找侧边栏容器。

* **左侧容器判据**：元素高度 > 屏幕高度50%，且 `getBoundingClientRect().left` < 100。
* **右侧容器判据**：元素高度 > 屏幕高度30%，且 `getBoundingClientRect().right` > (windowWidth - 100)。

#### 第二步：提取策略 (Extraction Strategy)

* **左侧 (递归提取)**：
* 需要处理**动态加载**：部分菜单仅在点击父级后才渲染子级。
* **逻辑**：遍历节点 -> 判断是否有折叠箭头 -> 模拟点击展开 -> 重新抓取子节点 -> 递归。


* **右侧 (平铺提取)**：
* 直接获取文本和 `href`。
* **校验**：提取出的文本通常应存在于主内容区（Main Content）的 Header 标签中。



### 3. 代码实现逻辑示例

```typescript
import puppeteer, { ElementHandle } from 'puppeteer';

interface MenuNode {
  title: string;
  link?: string;
  children?: MenuNode[];
  depth: number;
}

async function analyzePage(url: string) {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  await page.goto(url, { waitUntil: 'networkidle0' });

  // 1. 获取视口宽度用于判断位置
  const viewportWidth = await page.evaluate(() => window.innerWidth);

  // 2. 查找可能的菜单容器
  const potentialMenus = await page.$$('nav, aside, div[class*="menu"], div[class*="nav"], div[class*="sidebar"]');

  let leftMenuHandle: ElementHandle | null = null;
  let rightMenuHandle: ElementHandle | null = null;

  for (const handle of potentialMenus) {
    const box = await handle.boundingBox();
    if (!box) continue;

    // 逻辑：左侧菜单通常紧贴左边，且占据较大高度
    if (box.x < 50 && box.height > 300) {
      // 可能是左侧菜单，取最外层或最匹配的一个
      if (!leftMenuHandle) leftMenuHandle = handle; 
    }
    
    // 逻辑：右侧菜单在右侧区域，通常宽度较窄
    if (box.x > viewportWidth * 0.7 && box.height > 100) {
      rightMenuHandle = handle;
    }
  }

  // 3. 提取函数（通用）
  const extractLinks = async (container: ElementHandle) => {
    return await container.evaluate((el) => {
      const items = Array.from(el.querySelectorAll('a')); // 或者是 li > span
      return items.map(a => ({
        text: a.innerText.trim(),
        href: a.getAttribute('href'),
        indent: parseInt(window.getComputedStyle(a).paddingLeft || '0') // 通过padding判断层级
      })).filter(i => i.text);
    });
  };

  const leftTree = leftMenuHandle ? await extractLinks(leftMenuHandle) : [];
  const rightToc = rightMenuHandle ? await extractLinks(rightMenuHandle) : [];

  console.log("Left Menu (Navigation):", leftTree.slice(0, 3)); // 打印前3个示例
  console.log("Right Menu (TOC):", rightToc.slice(0, 3));

  await browser.close();
}

```

### 总结

1. **不要硬编码 class**：文档站经常改版，class 是不稳定的。
2. **使用几何位置 (Geometry)**：屏幕左 1/4 为导航，右 1/4 为 TOC，这是最稳健的逻辑。
3. **处理懒加载**：如果左侧菜单抓取不全，必须在代码中加入 `click()` 展开父菜单的操作。
