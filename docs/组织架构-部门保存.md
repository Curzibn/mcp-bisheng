# 美团企业版开放平台

## 部门保存接口

## 1.概述

批量部门保存接口，如果部门不存在则新增部门，如果部门存在则更新部门，更新部门时如果字段为null则不更新对应字段，非null时则更新，单次调用最大保存部门数量为50

## 2.接口基本信息

| 名称 | 描述 |
| --- | --- |
| 请求方式 | POST |
| 调用地址 | 测试环境：`https://waimai-openapi.apigw.test.meituan.com/api/sqt/open/org/batch/save`  
正式环境：`https://bep-openapi.meituan.com/api/sqt/open/org/batch/save` |
| 调用方 | 客户平台 |
| 响应方 | 美团企业版 |
| 响应超时时间 | 5秒 |
| 调用限频 | 每分钟访问不超过100次，每天累计访问不超过100000次 |

**OrgInfo字段说明**

| 名称 | 类型 | 是否必填 | 示例 | 说明 |

| parentOrgId | Long | 否 | 0 | 父部门id，美团侧对部门的唯一标识，如果上级部门是公司填0，新增部门和更新上级部门时，parentOrgId和parentExternalOrgId必传其一 |

| orgAdminList | List<[StaffUniqueMarkInfo](https://bep-openapi.meituan.com/api/sqt/openplatform_web/site/index.html#/apiDoc/orgSave#StaffUniqueMarkInfo)\> | 否 | 见[StaffUniqueMarkInfo](https://bep-openapi.meituan.com/api/sqt/openplatform_web/site/index.html#/apiDoc/orgSave#StaffUniqueMarkInfo) | 部门主管列表，一个部门最多200个主管，如果为空列表，则表示清空部门主管 |

**StaffUniqueMarkInfo字段说明**

| 名称 | 类型 | 是否必填 | 示例 | 说明 |

| staffId | Long | 否 | 1 | 美团企业版为员工分配的唯一标识 |
| staffIdentifier | String | 否 | code11 | 企业侧的员工唯一标识，staffId和staffIdentifier二者必传其一，如果二者均传值，则以staffId为准 |

| 10010003 | content不合法 | 详细阅读content参数加密说明（[签名实例](https://bep-openapi.meituan.com/api/sqt/openplatform_web/site/index.html#/apiDoc/signatureInstance)），确认content加密方式和content解密前传参是否正确 |
| 10010004 | ts缺失或ts时间已过期 | 确认ts是否传值并为13位时间戳，如果正确传值，则确认请求发起时间与美团企业版接受请求的时间差是否超过10分钟 |
| 10010005 | entId不能为空 | entId参数不可为空，如果未拿到entId参数，可以咨询客户经理获取 |
| 20010001 | accessKey不合法 | 检查accessKey是否为客户经理给到的值，如果accessKey值正确，确认调用环境是否和accessKey一致，如使用测试环境的accessKey调用线上的接口 |
| 20010002 | 请求path不合法 | 检查接口调用地址是否正确，如是否有非法字符 |
| 20010003 | 鉴权失败，无接口访问权限 | 将接口调用地址给到客户经理，由客户经理检查接口权限是否开通并保存成功 |
| 20010004 | 越权访问，无法访问该企业数据，请检查entId的正确性 | 检查accessKey和entId两个参数的对应关系是否正确 |
| 30010001 | 访问频率过高 | 请确认接口访问频率，每个接口默认调用限频为每分钟不超过100次，超出调用频率会调用此错误 |

| 10080003 | 部门id和外部部门id为空 | 请检查orgId和externalOrgId字段是否传值，新增部门时，externalOrgId字段必传，更新部门时，orgId和externalOrgId二者必传其一 |

| 10081001 | 传入部门为空 | 请检查orgInfoList字段是否为空对象 |
| 40080000 | 部分部门处理失败 | 请查看响应结果中的result和itemMsg信息，根据解决方案进行调整 |
| 40080001 | 未知错误，请联系美团侧研发 | 请提供响应结果中的traceId参数，联系客户经理进行排查 |

### 4.2.result 错误码

| 错误码 | 错误描述 | 解决方案 |
| --- | --- | --- |
| 10081002 | 父部门不存在 | 请检查parentOrgId和parentExternalOrgId传值是否正确，且已经在美团企业版企业后台-组织架构菜单中存在，父部门需提前同步 |
| 10081003 | orgId对应部门不存在 | 请检查orgId对应的部门是否存在，如不存在，无法更新 |
| 10081004 | externalOrgId企业内重复 | 请检查企业内是否有重复externalOrgId，如有重复，请进行调整 |
| 10081005 | 部门名称不允许含有英文连接符“-”以及英文的“,”，请修改部门名称！ | 请检查orgName字段传值，部门名称不允许含有英文连接符“-”以及英文的“,” |
| 10081006 | 父部门为自己 | 请检查parentOrgId字段传值是否与orgId相同，或者parentExternalOrgId字段传值与externalOrgId相同，如无父部门，parentOrgId传值为0 |
| 10081007 | 部门名字为空 | 请检查orgName字段传值，新增部门时，orgName字段必传 |
