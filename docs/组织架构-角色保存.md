# 美团企业版开放平台

## 角色保存接口

## 1.概述

角色保存接口为角色管理体系中的第二步，如果企业需要用角色管理，需要按照：创建角色组→在角色组下创建角色→在角色中关联员工，这个顺序进行配置。

## 2.接口基本信息

| 名称 | 描述 |
| --- | --- |
| 请求方式 | POST |
| 调用地址 | 测试环境：`https://waimai-openapi.apigw.test.meituan.com/api/sqt/open/tag/batch/save`  
正式环境：`https://bep-openapi.meituan.com/api/sqt/open/tag/batch/save` |
| 调用方 | 客户平台 |
| 响应方 | 美团企业版 |
| 响应超时时间 | 5秒 |
| 调用限频 | 每分钟访问不超过100次，每天累计访问不超过100000次 |

| 名称 | 类型 | 是否必填 | 示例 | 说明 |

**TagInfo字段说明**

| 名称 | 类型 | 是否必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| tagGroupType | Integer | 是 | 1 | 角色组类型，0：职级角色组，1：普通自定义角色组。当type传0时，tagGroupId传值和externalTagGroupId传值自动忽略；当type传1时，tagGroupId和externalTagGroupId二者必传其一，如果两个字段都传值，则以tagGroupId为准。 |
| tagGroupId | Long | 否 | 1 | 角色组ID，美团侧对角色组的唯一标识 |
| externalTagGroupId | String | 否 | A01 | 角色组编码，企业侧对角色组的唯一标识 |
| tagId | Long | 否 | 33 | 角色ID，美团侧对角色的唯一标识，tagId和externalTagId二者必传其一，如果两个字段都传值，则以tagId为准，更新角色编码值时，需要传tagId |
| externalTagId | String | 否 | A001 | 角色编码，企业侧对角色的唯一标识，若tagId和externalTagId两个字段都传值，则以tagId为准 |
| tagName | String | 否 | 职级 | 角色名称，新增角色时，此字段必传 |

import java.util.Objects;

    private static SqtClient sqtClient = null;

    static {
        // 初始化SqtClient，只需要初始化一次即可
        // entId，accessKey，secretKey需要根据不同环境动态的设置获取
        sqtClient = new SqtClient.Builder()
                .setEntId(CommonConstants.entId)
                .setAccessKey(CommonConstants.accessKey)
                .setSecretKey(CommonConstants.secretKey)
                .build();
    }

    public static void main(String[] args) throws MtSqtException {
        // 1. 构建请求对象
        // 1.1 设置通用参数
        TagSaveRequest tagSaveRequest = new TagSaveRequest();
        tagSaveRequest.setTs(System.currentTimeMillis());
        tagSaveRequest.setEntId(sqtClient.getEntId());
        // 1.2 封装需要保存的角色信息
        TagSaveRequest.TagInfo tagInfo = new TagSaveRequest.TagInfo();
        tagInfo.setTagGroupType(1);
        tagInfo.setExternalTagGroupId("TAG001");
        tagInfo.setExternalTagId("tag1");
        tagInfo.setTagName("角色1");
        tagSaveRequest.setTagList(Collections.singletonList(tagInfo));
        // 2. API调用
        // 注意：超时时间默认以请求对象中注解ApiMeta上设置的为准，也可以自定义传递对应的超时时间
        BaseApiResponse<List<TagSyncResult>> response = sqtClient.invokeApi(invokeUrl, tagSaveRequest, null, null);

        if (response == null) {

        // 4. 获取请求结果

        } else {
